# CodeAlpha CGPA Calculator

## Internship
CodeAlpha C++ Programming Internship

## Task
Task 1 - CGPA Calculator

## Description
This C++ console application calculates a student's CGPA using the grade point and credit hours of each course.

## Features
- Accepts multiple courses
- Accepts course name, grade point, and credit hours
- Calculates total credits
- Calculates total grade points
- Calculates final CGPA
- Displays a formatted result

## Concepts Used
- C++
- Structures
- Vectors
- Loops
- Input/Output
- Arithmetic operations
- Formatted output

## How to Run in VS Code
1. Open the project folder in Visual Studio Code.
2. Open `main.cpp`.
3. Make sure a C++ compiler such as MinGW/g++ is installed.
4. Open Terminal in VS Code.
5. Compile:
   `g++ main.cpp -o cgpa`
6. Run on Windows:
   `.\cgpa`
